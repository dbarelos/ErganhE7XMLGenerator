# ErganhE7XMLGenerator

H εφαρμογή παράγει XML ισοδύναμο με έντυπο Ε7 για μαζικές αναγγελίες λήξης εργασίας για λύση συμβάσεων ορισμένου χρόνου, σύμφωνα με τις αντίστοιχες προδιαγραφές που δίνει η ΕΡΓΑΝΗ ΙΙ και ισχύουν απο τις αρχές του 2026 και μέχρι τουλάχιστον τη σύνταξη του παρόντος.

Τα δεδομένα στην εφαρμογή εισάγονται μέσω κατάλληλου αρχείου Excel. Η δομή του αρχείου περιγράφεται στην ενότητα «Αρχείο Excel»
Το παραγόμενο XML μπορεί να μεταφορτωθεί στη λειτουργία Βοηθητικά > Ομαδικές Υποβολές > Εισαγωγή από αρχείο στον ιστότοπο του ΕΡΓΑΝΗ όπου επιλέγετε «ΨΗΦΙΑΚΗ ΑΝΑΓΓΕΛΙΑ ΛΗΞΗΣ ΕΡΓΑΣΙΑΣ - Λύση Σύμβασης Ορισμένου Χρόνου»
